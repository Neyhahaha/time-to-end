## 1. 产品概述

桌面倒计时小程序——一款精致优雅的倒计时工具，帮助用户追踪重要时刻。目标用户为需要管理时间节点的办公人群、学生及生活规划者，核心价值在于将时间可视化，让每一秒都有仪式感。

## 2. 核心功能

### 2.1 用户角色
无需角色区分，单用户本地应用。

### 2.2 功能模块
1. **主页面**：倒计时展示、新建倒计时、倒计时列表管理
2. **设置面板**：主题切换、通知提醒

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 主页面 | 倒计时展示区 | 大字体动态倒计时显示，支持天/时/分/秒切换，环形进度动画 |
| 主页面 | 新建倒计时 | 弹窗表单：事件名称、目标日期时间、选择图标/颜色标签 |
| 主页面 | 倒计时列表 | 卡片式列表展示所有倒计时，支持编辑/删除/置顶 |
| 主页面 | 快捷操作栏 | 一键新建、筛选排序、视图切换 |
| 设置面板 | 主题设置 | 亮色/暗色主题切换 |
| 设置面板 | 通知提醒 | 倒计时到期浏览器通知提醒 |

## 3. 核心流程

用户打开应用 → 查看已有倒计时列表 → 点击新建按钮 → 填写事件名称和目标日期 → 保存 → 倒计时开始实时倒计 → 倒计时到期触发通知提醒

## 4. 用户界面设计

### 4.1 设计风格
- **风格方向**：新拟态（Neumorphism）+ 毛玻璃质感，精致而温暖
- **主色调**：深空蓝 (#0F172A) 为底，珊瑚橙 (#FF6B6B) 为强调色，薄荷绿 (#4ECDC4) 为辅助色
- **按钮风格**：圆角胶囊按钮，新拟态凸起/凹陷效果
- **字体**：数字使用 JetBrains Mono（等宽，科技感），标题使用 Outfit（几何感，现代），正文使用 Noto Sans SC
- **布局风格**：居中大卡片焦点式布局，左右列表辅助
- **图标风格**：Lucide 线性图标

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 主页面 | 倒计时展示区 | 超大等宽数字、环形SVG进度条、呼吸光效动画、毛玻璃背景 |
| 主页面 | 新建倒计时弹窗 | 毛玻璃遮罩、表单输入框、日期时间选择器、颜色标签选择 |
| 主页面 | 倒计时列表 | 卡片网格布局、渐变色条、悬停放大效果、删除滑动手势 |
| 主页面 | 快捷操作栏 | 浮动操作按钮、筛选下拉菜单 |
| 设置面板 | 主题设置 | 开关切换、实时预览 |
| 设置面板 | 通知提醒 | 开关切换、提前时间选择 |

### 4.3 响应式设计
桌面优先设计，适配 1280px+ 宽屏，兼顾 1024px 笔记本屏幕。

### 4.4 动效设计
- 页面加载：倒计时数字逐位翻转动画
- 倒计时切换：卡片 3D 翻转过渡
- 进度环：平滑弧线动画
- 悬停：卡片微浮起 + 阴影加深
- 到期：脉冲光效 + 粒子庆祝效果
